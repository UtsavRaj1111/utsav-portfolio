# 🚀 Modern Engineering Portfolio | Utsav Raj Pratik

A high-performance, AI-driven developer portfolio designed for modern engineering impact. This project showcases a blend of clean architecture, interactive UI, and robust backend integration.

## ✨ Key Features

- **Interactive IDE Experience**: A custom code-editor interface showcasing profile data in real-time JSON format.
- **Dynamic Hero Section**: Multi-expert typing animation highlighting AI/ML, Full Stack, and Algorithm skills.
- **Glassmorphism UI**: Premium, high-transparency design system with smooth transitions and hover effects.
- **GitHub Integration**: Real-time project syncing and repository statistics directly from the GitHub API.
- **Responsive Architecture**: Fully optimized for mobile, tablet, and high-resolution desktop displays.
- **Backend Communication**: Functional Flask-powered contact system with real-time feedback.

## 🛠️ Tech Stack

- **Frontend**: Tailwind CSS, Vanilla JavaScript, Lucide Icons, Google Fonts.
- **Backend**: Python, Flask.
- **Interactions**: Intersection Observer API, CSS3 Keyframe Animations.
- **Assets**: Custom-designed branding and AI-generated project logos.

## 🚀 Getting Started

### Prerequisites
- Python 3.8+
- pip

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/UtsavRaj1111/utsav-portfolio.git
   cd utsav-portfolio
   ```

2. **Set up a virtual environment (optional but recommended)**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the development server**
   ```bash
   python app.py
   ```

5. **Open the browser**
   Navigate to `http://127.0.0.1:5000` to view the live portfolio.
